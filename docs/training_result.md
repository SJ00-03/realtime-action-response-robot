# Training Result

## 데이터셋 구성

- 데이터 출처: AI Hub 데이터 + 직접 수집 데이터
- 규모: 약 4만 장
- 클래스: `person`, `falldown`, `attack`, `smoking`
- 라벨링 도구: AnyLabeling
- 작업 내용: 라벨 생성, 누락 라벨 확인, 오분류 라벨 수정, 학습 구조 정리

---

## 학습 과정

1. 원본 데이터를 클래스 기준에 맞게 정리했습니다.
2. AnyLabeling으로 라벨을 생성하고 검수했습니다.
3. YOLO 학습 형식에 맞춰 데이터셋을 구성했습니다.
4. 커스텀 YOLO 모델을 학습했습니다.
5. Precision, Recall, mAP 지표를 확인했습니다.
6. `attack` / `smoking` 혼동 사례를 분석하고 데이터를 정제했습니다.
7. 정제된 데이터로 재학습해 성능을 개선했습니다.

## 클래스별 성능 확인 관점

| Class | 확인 포인트 |
|---|---|
| `person` | 일반 사람 탐지 안정성, 다른 위험 행동 클래스와의 구분 |
| `falldown` | 누운 자세, 낮은 박스 높이, 다양한 각도에서의 탐지 여부 |
| `attack` | 팔 동작과 상체 움직임이 큰 장면에서의 탐지 여부 |
| `smoking` | 손이 얼굴 주변에 위치한 장면에서의 탐지 여부 |

## 데이터 정제 내용

- 클래스 기준이 모호한 샘플을 재검토했습니다.
- 라벨 위치가 부정확한 박스를 수정했습니다.
- `attack`과 `smoking`처럼 혼동되는 클래스의 샘플을 집중적으로 확인했습니다.
- 실제 로봇 카메라 환경에서 발생할 수 있는 각도와 거리 차이를 고려해 데이터를 정리했습니다.
