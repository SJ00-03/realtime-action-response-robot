# Contribution

## 담당 역할 요약

이 프로젝트에서 저는 **데이터셋 전처리, YOLO 모델 학습, 웹 모니터링 UI 구현, Bluetooth 기반 로봇 제어 연동**을 담당했습니다.

팀 전체의 하드웨어 제작, STM32 전체 제어 로직, Hailo 변환 전체 과정은 팀 시스템 구성에 포함되지만, 제 직접 담당 범위로 표현하지 않습니다.

---

## 1. 데이터셋 전처리

- AI Hub 데이터와 직접 수집 데이터를 프로젝트 목적에 맞게 정리했습니다.
- 학습 가능한 폴더 구조로 이미지와 라벨을 구성했습니다.
- 감지 클래스는 `person`, `falldown`, `attack`, `smoking` 4개로 정리했습니다.
- AnyLabeling을 활용해 라벨링을 수행하고, 누락·오분류 라벨을 검수했습니다.

### 면접 설명 포인트

> 단순히 공개 데이터를 사용한 것이 아니라, 실제 로봇 안전관리 시나리오에 맞게 클래스를 재정의하고 라벨 품질을 검수해 모델 학습 성능을 개선했습니다.

---

## 2. AI 모델 학습

- YOLO 기반 커스텀 객체 탐지 모델을 학습했습니다.
- Precision, Recall, mAP 지표를 기준으로 학습 결과를 분석했습니다.
- `attack`과 `smoking`처럼 자세와 손 위치가 유사해 혼동되는 클래스를 집중적으로 확인했습니다.
- 오탐·미탐 사례를 바탕으로 데이터 정제와 재학습을 반복했습니다.

### 면접 설명 포인트

> 모델 성능을 단순 정확도만으로 판단하지 않고, 클래스별 혼동 사례를 확인한 뒤 데이터 품질 개선과 재학습으로 탐지 안정성을 높였습니다.

---

## 3. 웹 모니터링 UI 구현

- 실시간 카메라 영상을 확인할 수 있는 웹 화면을 구성했습니다.
- FPS 표시를 통해 추론 상태를 직관적으로 확인할 수 있게 했습니다.
- 위험 행동 감지 시 알림을 표시하도록 UI를 구성했습니다.
- 클래스별 감지 상태와 통계, 시스템 상태 정보를 한 화면에서 볼 수 있도록 정리했습니다.

### 면접 설명 포인트

> AI 모델 결과를 단순 콘솔 출력에 그치지 않고, 사용자가 실시간으로 판단할 수 있는 대시보드 형태로 시각화했습니다.

---

## 4. Bluetooth 제어 연동

- HC-06 Bluetooth 모듈을 활용해 스마트폰 제어와 로봇 제어 시스템을 연결했습니다.
- STM32 UART 통신을 기반으로 전진, 후진, 좌회전, 우회전, 정지 명령을 연동했습니다.
- 속도 조절 명령을 포함해 수동 제어 상황에서 로봇을 안정적으로 조작할 수 있도록 했습니다.

### 면접 설명 포인트

> AI 자동 감지뿐 아니라, 현장에서 사용자가 직접 개입할 수 있는 수동 제어 경로를 Bluetooth 통신으로 구성했습니다.
