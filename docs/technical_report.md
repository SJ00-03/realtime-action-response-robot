# Technical Report

## 시스템 개요

이 프로젝트는 카메라 영상 기반 AI 인식과 임베디드 로봇 제어를 결합한 실시간 안전관리 로봇입니다. Raspberry Pi 5에서 영상 처리와 AI 추론을 수행하고, STM32F407이 모터와 경고 장치를 제어합니다.

감지 대상은 `person`, `falldown`, `attack`, `smoking`입니다.

---

## 전체 흐름

1. 카메라가 실시간 영상을 입력합니다.
2. Raspberry Pi 5가 프레임을 수신하고 전처리합니다.
3. YOLO 모델이 사람과 위험 행동을 탐지합니다.
4. MediaPipe Pose가 자세 정보를 보조적으로 분석합니다.
5. 웹 대시보드에 영상, FPS, 감지 상태, 통계를 표시합니다.
6. 위험 상태 또는 제어 명령은 STM32 제어 시스템과 연동됩니다.
7. Bluetooth App은 HC-06 모듈을 통해 STM32 UART 제어 명령을 전달합니다.

---

## 주요 구성 요소

| Component | Role |
|---|---|
| Raspberry Pi 5 | 영상 입력, AI 추론, 웹 UI 연동 중심 처리 |
| Hailo AI Accelerator | YOLO 추론 가속으로 실시간 처리 성능 확보 |
| YOLO | `person`, `falldown`, `attack`, `smoking` 객체·행동 탐지 |
| MediaPipe Pose | 사람 자세 기반 보조 판단 |
| OpenCV | 프레임 처리, 영상 표시, 시각화 |
| ByteTrack | 탐지 객체 추적 및 ID 유지 |
| STM32F407 | 모터, LED, Buzzer 등 하드웨어 제어 |
| HC-06 Bluetooth | 스마트폰 앱과 STM32 UART 통신 연결 |
| Web UI | 실시간 모니터링, FPS, 위험 알림, 감지 통계 표시 |

---

## AI 처리 구조

YOLO는 영상 프레임에서 4개 클래스를 탐지합니다. MediaPipe Pose는 사람의 관절 위치를 기반으로 자세 판단을 보조합니다. 두 결과를 함께 사용해 단일 모델 탐지에서 발생할 수 있는 순간 오탐을 줄이는 구조를 목표로 했습니다.

---

## 웹 모니터링 구조

웹 UI는 실시간 카메라 화면, FPS, 위험 행동 감지 알림, 클래스별 상태와 통계를 표시합니다. 사용자는 모델이 어떤 클래스를 감지하고 있는지, 시스템이 정상 동작 중인지 빠르게 확인할 수 있습니다.

> 참고: 저장소의 폴더명은 현재 구조에 맞춰 `sever/`를 유지합니다. 코드 참조 가능성이 있으므로 임의로 `server/`로 변경하지 않습니다.

---

## 로봇 제어 구조

STM32F407은 모터, LED, Buzzer 등 로봇의 물리 출력 장치를 제어합니다. Bluetooth 제어는 HC-06 모듈과 UART 통신을 사용하며, 스마트폰 앱에서 전진, 후진, 좌회전, 우회전, 정지, 속도 조절 명령을 전달할 수 있습니다.
